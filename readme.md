# Exercism Python 🐍

Este repositorio contiene soluciones a ejercicios de **[Exercism](https://exercism.org/)**, una plataforma de aprendizaje enfocada en mejorar la **lógica de programación**, la **resolución de problemas** y las **buenas prácticas de desarrollo** a través de retos prácticos.

Los ejercicios aquí resueltos están desarrollados en **Python**, uno de los lenguajes más versátiles y utilizados tanto en entornos académicos como profesionales.

---

## 🎯 Objetivo del repositorio

El propósito principal de este repositorio es:

- Practicar y fortalecer la **lógica de programación**
- Mejorar la capacidad de **análisis y solución de problemas**
- Familiarizarse con la **sintaxis y características de Python**
- Aplicar **buenas prácticas** de escritura de código
- Llevar un seguimiento del progreso personal en Exercism

---

## 🧠 ¿Qué es Exercism?

Exercism es una plataforma gratuita que ofrece ejercicios de programación organizados por lenguajes. Cada ejercicio plantea un problema específico que debe resolverse escribiendo código y pasando una serie de pruebas automatizadas.

Más información en:  
👉 https://exercism.org/

---

## 🛠 Lenguaje utilizado

- **Python 3**

Los ejercicios están diseñados para ejecutarse con versiones modernas de Python, siguiendo las convenciones y estilos recomendados por la comunidad.
